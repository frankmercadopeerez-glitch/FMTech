# Expansión comercial FMTECH

Esta carpeta organiza las próximas soluciones verticales de la marca. La página de odontología ya está construida en `/odontologos-cartagena/`; las demás se activarán cuando exista contenido específico y verificable para cada sector.

- `medicos/`: consultas, especialistas, servicios y solicitud de cita.
- `veterinarias/`: servicios, equipo, urgencias, sedes y contacto.
- `peluquerias/`: servicios, portafolio, ubicación y reserva.

No publicar páginas vacías ni duplicar la misma propuesta entre sectores. Cada landing debe tener investigación, textos, SEO y demostraciones propios.
